# SkyGlass Weather App

Aplicação de previsão do tempo desenvolvida com HTML, CSS e JavaScript utilizando a OpenWeather API.

## Funcionalidades
- Busca de cidades
- Temperatura atual
- Sensação térmica
- Umidade
- Velocidade do vento
- Previsão das próximas horas

## Tecnologias
- HTML
- CSS
- JavaScript
- OpenWeather API
