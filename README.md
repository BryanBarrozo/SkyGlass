# SkyGlass

Aplicação web de previsão do tempo desenvolvida com HTML, CSS e JavaScript puro utilizando a OpenWeather API.

O projeto apresenta informações climáticas em tempo real através de uma interface moderna inspirada em glassmorphism, incluindo previsão das próximas horas e indicadores climáticos detalhados.

## Funcionalidades

- Busca de cidades em tempo real
- Temperatura atual
- Máxima e mínima do dia
- Previsão para as próximas horas
- Ícones climáticos dinâmicos
- Sensação térmica
- Umidade do ar
- Velocidade do vento
- Visibilidade
- Pressão atmosférica
- Nível do mar
- Interface moderna com efeito glassmorphism
- Atualização dinâmica dos dados via API

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Font Awesome

## Conceitos Aplicados

- Manipulação de DOM
- Consumo de API com `fetch`
- Programação assíncrona com `async/await`
- Atualização dinâmica da interface
- Glassmorphism UI
- Flexbox & Grid
- Organização de componentes visuais
- Tratamento de dados JSON

## Objetivo do Projeto

O objetivo do projeto foi praticar consumo de APIs, manipulação de dados em tempo real e desenvolvimento de interfaces modernas utilizando JavaScript puro.
